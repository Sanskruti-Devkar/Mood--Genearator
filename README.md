# Mood Palette Generator (CSS Popover Practice Project)

This project is a front-end Mood Palette Generator created using HTML and CSS. The website uses different color-based mood buttons, and when a user clicks a color, a popover appears with information describing that mood and emotions related to it.

Live demo:https://sanskruti-devkar.github.io/Mood--Genearator/

## Features

- Color-based mood selection buttons
- Interactive popover information sections
- Mood descriptions based on colors
- Creative and visually engaging UI
- Clean and responsive layout design
- Emotion-inspired color palette concept



##️ Technologies Used

- HTML5
- CSS



## What I Practiced

In this project, I learned and practiced:

- Using popovers/tooltips in UI design
- Creating interactive button sections
- Applying color psychology concepts
- Structuring informational content layouts
- Improving spacing and alignment using CSS
- Designing creative and user-friendly interfaces



## Mood Examples

- Yellow → Happy Mood
- Blue → Calm Mood
- Red → Energetic Mood
- Green → Relaxed Mood
